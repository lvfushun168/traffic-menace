# Traffic Menace — 中文灰盒原型

这是根据《Traffic Menace》产品需求文档 PRD v0.3 制作的独立 Godot 4 灰盒，用来验证：

> 观察后车意图 → 减速 / 横向卡位 / 使用道具 → 看见 NPC 反应 → 追尾、拥堵与连锁事故。

当前文档与原型实现同步于 **2026-09-15**；产品规划与当前灰盒范围的区别见项目根目录的 PRD v0.3。9 个 headless 烟测脚本当前全部通过；系统烟测约覆盖 60 秒，完整 8 分钟的真人试玩与数值平衡仍待验证。

## 启动

需要 Godot 4.7+。在本目录执行：

```bash
godot --editor project.godot
```

或直接运行：

```bash
godot --path . --editor
```

也可以在 Godot 项目管理器中导入本目录，然后按 F6/F5。

## 操作

| 动作 | 键位 |
| --- | --- |
| 横向移动 | ← / → |
| 减速 | ↓ |
| 加速 | ↑ |
| 直接使用对应道具 | 1 / 2 / 3 |
| 暂停 / 继续 | Esc |
| 重新开始 | R |

道路固定为五车道；在 1280×720 下总宽约 510px，每道约 102px。单道宽度按基础玩家车身 68px × 1.5 计算，`WIDE BODY` 只扩大玩家车身，不改变道路宽度。玩家车位于屏幕上方约 1/4，下面保留大块区域观察车流和混乱。开局 6 辆车，前 10 秒约 8 辆、30 秒约 15 辆、60 秒恢复到 30 辆，难度随后逐步将动态上限提高到 80 辆。

道路材质已经加入第一版：`assets/road/road_surface.svg` 是可平铺沥青源稿，`assets/road/sidewalk_surface.svg` 是路肩/人行道源稿；窗口运行时优先读取 SVG，无法使用导入器时自动生成同尺寸的 `ImageTexture`，车道线、反光道钉和磨损标记单独绘制。所有道路标记统一使用正向 `road_scroll`，与建筑、道路事件和道具一样从上往下移动。这样后续可以只换材质，不改车道碰撞和交通规则。完整的尺寸、配色与替换路线见项目根目录的 [道路美术与汇入方案](../../ROAD_ART_DIRECTION.md)。

## 司机与压线行为

NPC 的 `lane` / `target_lane` 表示路线意图，车身位置使用连续的横向坐标平滑移动，不会吸附回车道中心。三种司机可以通过以下观察线索区分：

- **Cautious：** 更早减速、保持更大跟车距离、换道慢且等待更久，通常靠近车道中心巡航。
- **Normal：** 中等反应和换道速度，巡航时保留轻微横向偏移。
- **Aggressive：** 反应距离更短、换道更快、等待更少；会按实际车身前后空隙选择相邻车道，完成一段后还能继续逐道找缝。准备超车时会先靠近车道分隔线，进入超车后速度约 69，切入玩家侧方的短暂冲刺最高可达 104，车身可能自然压住两道之间的虚线。

三种司机的巡航、跟车和超车目标速度统一提高 15%；刹车速度、刹车减速度、反应距离和安全净距保持不变。

压线不是特殊轨道：障碍物、合流和其他车辆都会按 NPC 的实际车身矩形检查占用车道，因此大型车辆也会被限制在道路边界内。所有 NPC 都把玩家车身和车尾安全距离当作避让区域；玩家不主动横向切入时，后车会预测净距、限速、刹车或等待，不会通过追尾伤害玩家。玩家明确横向切入并排行驶的车辆时，仍会触发侧向碰撞。

NPC 之间也遵守真实车身和相对速度规则：统一刹车减速度为 **20 km/h/s**，从 60 km/h 刹停约需 3 秒；正常无输入车流会提前跟车，尽量不互撞。只有前方因玩家误导类道具、道路障碍或既有事故突然减速，且后车刹车距离确实不足时，才可能形成带原因记录的连锁碰撞。`FAKE BRAKE LIGHT` 与 `BLACK SMOKE` 会把受影响车辆的目标速度压到 10 km/h，但实际速度仍按物理刹车率下降；低于 12 km/h 的轻微接触会无伤分离，高于阈值才记为事故。

## 路线规划与真人式避让

- 车辆发现慢车、事故车或封道时，会把反应距离、相对速度、刹车距离和横向移动时间合并成预警距离；变道前还会检查从当前车身到目标点的整段扫掠路径。
- Aggressive 会在五道车道图上搜索最多 4 次相邻车道变更，每次只移动一条车道；完成一跳后用最新车流重新找缝。Normal / Cautious 也会找实际空隙，但更倾向减速和等待。
- `PREPARE OVERTAKE` 表示打灯、靠近分隔线并观察；`AVOID` 表示已经提交避障路线；`FOLLOW` / `BLOCKED` 表示按前车速度跟车或等待；完成变道后进入 `RECOVER`，不会立即蛇形返回。
- 玩家连续左右变道不会把所有 NPC 长时间锁在远处：只有玩家的实际横向扫掠进入 NPC 车身才触发侧撞保护；后车只在真正被限速或纠正位置时短暂避让，进入安全侧道后会保持路线完成超车。
- 每个物理帧会按障碍紧迫度和司机优先级分配横向路线预约，同一空隙只允许一辆车先提交，其他车辆会刹车、换另一侧或等待。
- 开局主路车辆按车道错峰，屏幕底部刷新和支路合流都使用实际车身宽高、前后净距和相对速度检查；没有安全空隙时改选车道或留在入口，不把车硬插进车流。
- 支路队列存在、且某个边侧空隙只差一点时，主路只会由最近的一辆后车短暂降速制造拉链窗口；车距恢复后它会重新加速，不会把整条主路变成礼让墙。已汇入车辆会先保持主路流速离开入口，再恢复自己的横向偏移。
- 无障碍、无慢车和无路线冲突时，NPC 保持当前车道，只做很小的连续横向修正；随机偏移不会把相邻车道的车身推到一起。

## 道具规则

- HUD 底部有 3 个永久道具槽；本局内道具不会因使用而消失，可以反复使用。
- 碰到道路上的 `?` 会自动拾取，不需要按键。
- 有空槽时自动放进第一个空槽；三槽全满时，交通暂停并显示替换界面，必须按 1/2/3 选择被替换的槽位。
- 新道具替换完成后会自动选中；被替换的被动效果立即失效，已生成的障碍会持续到自身结束。
- 主动道具共用 3 秒冷却；被动道具拾取后立即生效，不占用冷却。
- 按 R 重开后恢复为初始的“漏油”道具加两个空槽。

## 车道汇入

- 支路不是常驻屏幕装饰：只有合流车辆获准生成时，才会创建与车辆绑定的动态道路段；道路段从屏幕上方约 `y = -260` 进入，随镜头向下移动，完成并线后和车辆一起离开并回收。没有动态道路段时，屏幕两侧不绘制固定“管道”。
- 开局主路车辆按纵向错峰放置，并额外保留少量合流容量；车流会从 6 辆逐步增加，主干道接近上限或暂时没有真实车身空隙时，车辆只在 HUD 中排队等待。现在同侧最多同时推进 2 个动态道路段，但两段之间至少保留 260px 纵向间距，避免道路段重新连成固定管道。
- 左支路的第一落点固定为 L1，右支路的第一落点固定为 L5；车辆不会从支路直接横穿到中间车道抢位置。
- 出现真实前后空位后，车辆沿带宽度的曲线路径连续并线；路径会检查车身扫掠、相对速度、玩家安全区、障碍和其他汇入车。开始并线后达到提交进度会继续完成，不会因下一帧短暂变窄而瞬移回入口。
- 合流道路段和车辆共用同一条动态贝塞尔路径、合流点纵坐标和进度；道路段抵达判定线后才检查真实空隙。目标外侧车道被车身、障碍、玩家、封道或其他合流车挡住时，车辆与道路段一起暂停，空位释放后继续。
- 完成外侧车道并线后，车辆会短暂跟上主路流速离开动态道路段，再复用普通 AI 的相邻车道规划逐道向 L2/L3/L4 移动。
- 主路车流较稀且玩家前方约 360px 没有近距离阻挡时，会额外从屏幕底部补入少量 `REAR CHASE` 激进车；它们优先在玩家当前车道以高于玩家 15–25 km/h 的速度追上，再按真实空隙择机超车。
- “支路合流”道路事件会临时提高入口刷新频率，观察入口车辆横向并入主干道。

## 建议灰盒验证流程

1. 先观察开局下方逐步进入的车流，重点看“激进司机”“准备超车”、转向箭头和压在线上的车身。
2. 看到后车准备变道后，按住 ↓ 让它靠近，再横向移动到它的目标车道。
3. 保持约 1 秒，观察“堵住了！”、急刹、等待和安全跟车；使用误导类道具后再观察刹车距离不足时的偶发连锁事故。
4. 直接按 1/2/3 使用对应道具，观察障碍、误导和 NPC 路线变化。
5. 碰到 `?` 测试自动拾取；三槽全满时确认交通暂停、替换提示和新道具自动选中。
6. 继续运行约 60 秒，观察从屏幕上方进入的动态支路、等待汇入车辆、道路事件、分数、困住车辆和堵塞倍率。

## 灰盒范围

保留中文 HUD、事件记录、浮动文字、屏幕震动、道路事件、五道车辆人格、NPC 避让、事故连锁、三槽道具和 8 分钟流程。道路已经加入第一版可平铺材质与合流标线；车辆、道具和环境细节仍是灰盒，暂不加入完整正式像素美术、音效、移动端 Tilt / Touch、图鉴、局外成长或生产级架构。
